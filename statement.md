Problem Statement:

Ineffective Tracking: Users struggle to effectively track, manage, and prioritize daily and long-term responsibilities.
Lack of Centralization: There is no single, easily editable system for distinguishing between current and completed tasks.
Consequences: Leads to missed deadlines, reduced productivity, and unnecessary cognitive load.
Goal: To provide a focused, intuitive, and simple solution for personal task management.
scope of the porject.

Task Creation: Allow the user to input a new task, including a title and an optional description.
Task Listing: Display a clear, easily readable list of active tasks.
Task Editing: Enable the user to modify the title and description of any existing active task.

Target User
The Task Manager application is designed for individuals who need a straightforward, personal tool to keep their day-to-day work or personal errands organized.

Primary Demographic: Students, freelancers, small business owners, and general users who handle a moderate, but manageable, number of tasks daily.

Key Needs:

Simplicity: They require an application that is easy to learn and use with minimal overhead or complex settings.

Clarity: They need a clear visual distinction between what still needs to be done and what has been finished.

Control: They require the ability to quickly edit task details when plans change.
